# Skill: repo navigation

Use this skill when a request names a symbol, a behaviour, or a file
you have not already read.

## How to find the code

1. Read `README.md` at the repo root first — it names the modules and
   what each one is for.
2. Locate the symbol by name before reading around it.
3. Read the whole function you intend to change, not just the line
   the request points at.

## What to report

Name the file you changed and the reason in one sentence. If you read
files without changing them, do not list them.
