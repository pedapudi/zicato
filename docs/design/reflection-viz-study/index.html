The reflection / "Instrument lens" design study — self-contained, theme-adaptive mockups for board-reflection, zicato's Measurement-System-Analysis layer for the evaluation contract. Reflection treats board + scoring + judges + gate as a measurement instrument and audits it: is it consistent (reliability), can it tell candidates apart (discrimination), is it correct per an independent adjudicator (validity), and is it tuned (calibration)? Each page below is one surface of that lens, in the established study format: inline CSS/SVG, static generic sample data, the full 16-theme Console picker (top-right), no network or build deps. The four pillars (what reflection measures)

Reliabilityis the instrument consistent? — measurable with no ground truth (repetition): noise floor σ, decision-flip rate, judge κ. → noise cloud
Discriminationcan it tell candidates apart? — differentiation per entry, redundancy, minimum detectable Δ, coverage. → judge audit
Validityis it correct? — only answerable by adjudication: judge audit, score↔behaviour coherence, loss-ordering τ. → x-ray · coherence
Calibrationis it tuned? (recommend-only) — margin from the noise floor, loss-term decomposition, judge pruning. → waterfall
