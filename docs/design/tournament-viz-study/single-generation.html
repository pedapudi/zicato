The single-generation zoom is the deepest level: one challenger's full dossier — not a series, a single multi-facet entity. The operator's question is one ruling: should this challenger have been promoted? What did its patch change, what did that do to each board / judge / drift-kind, and does it generalize (train-vs-holdout gap)? Six first-principles takes on the dossier — each preserving the existing candidate view's virtues: a cause→effect→verdict spine, everything comparison-relative to the champion (the same comparison the gate makes), decision-honest pending states, and drill-on-demand. Structure-agnostic: the same dossier reads identically whether this generation raced, swiss'd, or ran a gauntlet. One realistic sample, identical across all 6.
