The deepest zoom: one matchup. A single champion is challenged by a single child. This study explores 6 first-principles ways to answer the same decision from the same data — every option is fed the one shared sample below. The viz is identical for all tournament structures (gauntlet / single- & double-elim / swiss / racing); the only wrinkle is the frame label — a racing rung resolves a partial board and cuts a contestant (no crown), whereas the champion gate runs the full board and can promote. Each option marks that distinction where it matters.
