Typeface study — three modes, side by side

Each card applies one font option to the same representative zicato content — a section heading, body prose, a data table with tabular figures, a config/labels block, and one big metric — so prose, data, code, and headings are all exercised. Cards marked current show today's pairing. Compare within each mode, then open the composer to apply a chosen typeface to a full dashboard page in situ.

Picker study — 3 options per mode

control design · curated finalists

What an updated typeface picker could look like: instead of dozens of options, each of the three modes (Technical / Editorial / Display) offers exactly 3 curated finalists, with the current default pre-selected. Below are three candidate designs for the picker control itself — click a mode or option in any of them to see the selected state update and the live "body + code" preview strip change. Every micro-sample renders in the option's real faces. The 3-per-mode set is data-driven: swap finalists by editing the single PICKER_FINALISTS array (illustrative finalists shown — operator can swap freely).

Technical mode

all-mono · prose↔code axis

What to look for: the PROSE face carries body + heading; the CODE face carries the table, config, and big metric. The current pairing (iA Writer Mono prose) is the one under review — judge whether the prose mono reads warm and text-like beside JetBrains Mono's grid, and whether the two monos feel like one family or two.

Editorial mode

reading serif

What to look for: whether a serif typeset everywhere stays legible for DATA — check the table's tabular figures and the big metric. E2 swaps in JetBrains Mono for data/labels; decide if the mono numerals earn the break from the serif voice.

Display mode

geometric / condensed

What to look for: heading character vs. body calm. The current D2 pairs a condensed display face (Archivo Narrow) for headings against a geometric body (Space Grotesk); D1 and D3 unify on a single family — compare whether the condensed headline adds enough to justify the second face.
